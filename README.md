# julia.stan — a creative journal

Website that create a space for art archive, just the way your art is. No perfection, just process and progress!

Home page represents a place to find a tally, to show the effort that you put into your crafts. It highlights places to find inspiration nearby. 
Gallery page shows the juiciest part of the website. All your artwork and scraps, all in one place. 
Add entry page helps you document what you create.
